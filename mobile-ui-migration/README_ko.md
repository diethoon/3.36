# M36 모바일 UI 마이그레이션 (4.38MB WML)

**대상 게임 빌드:** Wayward_WML_ko.html / 2026-10-24-pre7  
**기준 HTML:** 4,383,674 bytes (4.38MB)  
**모드 버전:** 1.0.0

이 모드는 4.38MB 최종 WML HTML의 기존 모바일 화면 구조를 유지하면서, 이전 19MB판에서 사용하던 편의 UI를 WML 모드로 옮깁니다.

## 적용 기능

- **전체화면 버튼:** 상단 삼선 메뉴 바로 왼쪽에 추가합니다. 전체화면 API가 허용되는 브라우저·앱에서 작동합니다.
- **상태 게이지 고정:** 행동 패널 상단에 플레이어 기력, 아내 기력·기분, 신뢰도, 매력, 흥분도를 2열로 표시합니다.
- **강조 나레이션 고정:** 최신 로그 문장 또는 진행 중 이벤트 문장을 게이지 아래에 고정 표시합니다. 행동 선택지 스크롤과 분리되어 함께 스크롤되지 않습니다.
- **영업 준비 바로가기:** 상태 패널의 ‘오후 영업 준비’ 제목을 누르면 기존 ‘이야기’ 탭으로 이동해 원래 게임의 ‘물자 채우기’, ‘시설 업그레이드’ 화면을 표시합니다. 준비 UI나 구매 동작을 복제하지 않습니다.
- **비활성 선택지 접기:** 사용 불가 선택지를 짧은 라벨과 사유로 축약하고, ‘외출’·‘마을 둘러보기’ 분류의 비활성 선택지는 기본 접힘 상태로 둡니다. 분류 제목을 누르면 펼치거나 다시 접을 수 있습니다.

세로 모바일 화면에만 추가 UI를 표시합니다. 가로 화면과 데스크톱에서는 고정 패널과 전체화면 버튼을 숨기고 기존 UI를 그대로 사용합니다.

## 설치

1. 압축 파일 안의 mobile-ui-migration 폴더를 게임의 기존 wml/mods 폴더에 복사합니다.
2. 기존 wml/mods/mods.js의 WML.enable([...]) 목록에 다음 항목을 추가합니다.

       "mobile-ui-migration",

   기존 목록을 통째로 교체하지 말고, 현재 활성화된 모드 항목은 그대로 보존하세요.
3. 게임을 새로고침합니다. WML 모드 관리자에서 **M36 모바일 UI 마이그레이션**이 작동 중으로 표시되는지 확인합니다.

WML 모드 폴더 가져오기를 지원하는 실행기에서는 mobile-ui-migration 폴더를 모드 관리자로 가져와도 됩니다.

## 안전 범위

이 모드는 다음 항목을 수정하지 않습니다.

- 게임 턴, 행동 선택 및 이벤트 해결
- 경제, 물자, 공급, 캐릭터 행동 및 RNG
- 세이브/로드 데이터와 게임 ID
- Undo 처리와 원본 게임 상태

WML의 레이아웃 훅으로 화면 트리를 감싸고, 기존 스크롤 영역·버튼·이벤트 처리는 그대로 둡니다. 비활성 버튼에는 표시용 속성만 추가하며 React 버튼 자체를 교체하지 않습니다.

## 호환성

이 패키지는 **4.38MB Wayward_WML_ko.html의 2026-10-24-pre7 빌드**를 대상으로 합니다. 6.74MB v4.0 빌드나 19MB 구형 HTML에 호환된다고 주장하지 않습니다.

전체화면은 브라우저 또는 실행기가 Fullscreen API를 허용해야 사용할 수 있습니다. 해당 API가 차단된 환경에서는 게임 자체는 계속 작동하고 전체화면 전환만 실패할 수 있습니다.
