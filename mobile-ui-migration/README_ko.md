# M36 모바일 UI 마이그레이션 (4.38MB WML)

**대상 게임 빌드:** Wayward_WML_ko.html / 2026-10-24-pre7
**기준 HTML:** 4,383,674 bytes (4.38MB)
**모드 버전:** 1.3.3

이 모드는 4.38MB WML 빌드 전용 모바일 UI 모드입니다. 원본 게임의 React 상태·위치 컴포넌트를 새로 그리지 않고, 원본 요소를 그대로 행동 선택지 위 고정 영역으로 옮깁니다.

## 적용 기능

- **원본 위치·인물 목록 이동:** 이야기 탭 안의 원본 위치·인물 목록(loe)을 통째로 재사용해 행동 선택지 위에 고정합니다. 이 목록의 현재 위치, 당신의 행동 상태, 인물별 기력·기분·신뢰·이목을 끄는 정도·흥분도(원본 표시 조건 충족 시), 관계 문구를 별도 계산으로 복제하지 않습니다. 흥분도 막대는 원본과 동일하게 수치가 5를 초과할 때만 표시됩니다. 상단 초상화 카드(Z0)는 원래 위치에 그대로 둡니다.
- **이야기 영역 정리:** 세로 모바일에서 이야기 탭 내부의 위치·인물 목록과 “당신의 대응이 필요한 상황” 목록을 제거해, 원래 이야기 기록(itt)과 하단 탭이 남도록 합니다. 영업 준비의 물자·시설 UI는 원본 기능을 유지한 채 선택지 위 고정 패널로 이동합니다. 별도 “강조 나레이션” 블록은 표시하지 않습니다.
- **전체화면 유지:** 전체화면 버튼으로 켜면 설정을 저장하고, 앱을 백그라운드로 내렸다가 복귀할 때 전체화면 복구를 다시 요청합니다. 전체화면 버튼으로 직접 종료하면 자동 복구 설정도 해제됩니다. 브라우저가 사용자 동작 없는 재진입을 차단하는 경우에는 자동 복구가 제한될 수 있습니다.
- **대화·게이지 고정:** 행동 이벤트의 원본 제목, 인물/행동 설명, 질문 문구, `당신 / 그녀` 게이지(원본 이벤트에서 제공될 때), 대화 상자를 선택지 위 고정 영역에 함께 배치합니다. 질문의 응답 버튼과 일반 선택지는 별도 스크롤 영역에 남기며, 원본 이벤트 콜백과 선택지 ID를 그대로 유지합니다. 선택지 스크롤 영역은 기존 가용 높이의 약 2/3로 제한합니다.
- **영업 준비·물자 채우기 이동:** 원본 영업 준비 컴포넌트의 물자 채우기, 목표 수량·가격 제한, 시설 개선 컨트롤을 이야기 영역에서 분리해 선택지 위 고정 패널로 옮깁니다. 원본 dispatch와 상태 연결은 그대로 유지합니다.
- **그녀의 속마음 고정:** 원본 `Znt` 초상화/인물 컴포넌트가 렌더링하는 `그녀의 속마음` 카드만 찾아 세로 화면에서 하단 sticky로 고정합니다. 카드 너비는 내용 길이에 맞춰 늘어나되 가용 너비를 넘으면 줄바꿈합니다. 원본 접기/펼치기 핸들러와 본문을 그대로 유지합니다.
- **손님 정보 원본 유지:** 손님 이름·주문·팁·응대 상태를 모드에서 임의로 두 줄로 재배치하거나 말줄임 처리하지 않습니다. 게임 원본 행과 상세 팝오버를 그대로 사용해 좁은 화면에서도 원본 정보와 상호작용을 보존합니다.
- **비활성 행동 축약·접기:** 사용 불가 선택지를 짧은 이름과 사유로 축약합니다. ‘일하기’, ‘외출’, ‘마을 둘러보기’ 분류에 비활성 선택지가 있으면 기본으로 접고, 분류 제목을 눌러 펼치거나 다시 접을 수 있습니다.

상태 패널 이동은 세로 모바일 화면에만 적용합니다. 가로 화면과 데스크톱에서는 원본 상태·이야기 구성 그대로 유지하며, 추가 고정 패널과 전체화면 버튼은 숨깁니다.

## 설치

1. 압축 파일 안의 mobile-ui-migration 폴더를 게임의 기존 wml/mods 폴더에 복사합니다.
2. 기존 wml/mods/mods.js의 WML.enable([...]) 목록에 다음 모드 ID를 추가합니다.

       "mobile-ui-migration",

   기존 활성 모드 항목을 지우거나 목록 전체를 교체하지 말고, 기존 목록에 항목 하나만 추가하세요.
3. 게임을 새로고침합니다. WML 모드 관리자에서 **M36 모바일 UI 마이그레이션 1.3.3**이 로드되었는지 확인합니다.

WML 모드 폴더 가져오기를 지원하는 실행기에서는 압축을 푼 mobile-ui-migration 폴더를 모드 관리자로 가져와도 됩니다.

## 안전 범위

이 모드는 다음 게임 동작이나 데이터를 변경하지 않습니다.

- 게임 턴, 행동 선택 및 이벤트 해결
