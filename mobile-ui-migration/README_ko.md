# M36 모바일 UI 마이그레이션 (4.38MB WML)

**대상 게임 빌드:** Wayward_WML_ko.html / 2026-10-24-pre7
**기준 HTML:** 4,383,674 bytes (4.38MB)
**모드 버전:** 1.1.0

이 모드는 최종 4.38MB WML HTML의 기존 모바일 화면과 게임 동작을 유지하면서, 이전 19MB판에서 사용하던 모바일 편의 UI를 WML 모드로 이식합니다.

## 적용 기능

- **전체화면 버튼:** 상단 삼선 메뉴 바로 왼쪽에 추가합니다. 브라우저 또는 앱이 Fullscreen API를 허용하면 전체화면 진입과 종료가 가능합니다.
- **고정 위치·상태 영역:** 행동 패널 상단에 플레이어와 아내의 현재 위치를 표시합니다.
- **2열 상태 게이지:** 플레이어 기력, 아내 기력·기분, 신뢰도, 주목도, 흥분도를 두 열로 고정 표시합니다.
- **고정 대화·이벤트:** 진행 중인 대화나 이벤트가 있을 때만 해당 문장과 종류별 제목을 게이지 아래에 고정 표시합니다. 가장 최근의 일반 로그를 대화인 것처럼 대신 표시하지 않습니다.
- **영업 준비 바로가기:** 고정 영역의 ‘오후 영업 준비’를 누르면 기존 ‘이야기’ 탭으로 이동해 게임 원래의 ‘물자 채우기’와 ‘시설 업그레이드’ 화면을 보여줍니다. 구매·업그레이드 기능을 복제하지 않습니다.
- **비활성 행동 축약·접기:** 사용 불가 선택지를 짧은 이름과 사유로 축약합니다. ‘일하기’, ‘외출’, ‘마을 둘러보기’ 분류에 비활성 선택지가 있으면 기본으로 접고, 분류 제목을 눌러 펼치거나 다시 접을 수 있습니다.

추가 UI는 세로 모바일 화면에서만 표시합니다. 가로 화면과 데스크톱에서는 고정 패널과 전체화면 버튼을 숨기며, 기존 레이아웃을 변경하지 않습니다.

## 설치

1. 압축 파일 안의 mobile-ui-migration 폴더를 게임의 기존 wml/mods 폴더에 복사합니다.
2. 기존 wml/mods/mods.js의 WML.enable([...]) 목록에 다음 모드 ID를 추가합니다.

       "mobile-ui-migration",

   기존 활성 모드 항목을 지우거나 목록 전체를 교체하지 말고, 기존 목록에 항목 하나만 추가하세요.
3. 게임을 새로고침합니다. WML 모드 관리자에서 **M36 모바일 UI 마이그레이션 1.1.0**이 로드되었는지 확인합니다.

WML 모드 폴더 가져오기를 지원하는 실행기에서는 압축을 푼 mobile-ui-migration 폴더를 모드 관리자로 가져와도 됩니다.

## 안전 범위

이 모드는 다음 게임 동작이나 데이터를 변경하지 않습니다.

- 게임 턴, 행동 선택 및 이벤트 해결
- 경제, 물자, 공급, 캐릭터 행동 및 RNG
- 세이브/로드 데이터와 게임 ID
- Undo 처리와 원본 게임 상태

WML 레이아웃 훅으로 기존 React 화면에 고정 패널을 추가하고, 원래 행동 버튼과 스크롤 영역을 유지합니다. 비활성 버튼은 교체하지 않고 표시용 속성과 접힘 상태만 적용합니다. ‘물자 채우기’와 ‘시설 업그레이드’도 게임 원래 UI를 그대로 사용합니다.

## 호환성 및 검증 범위

이 패키지는 **4.38MB Wayward_WML_ko.html / 2026-10-24-pre7** 빌드 전용입니다. 6.74MB v4.0 빌드나 19MB 구형 HTML과 호환된다고 주장하지 않습니다.

4.38MB HTML을 대상으로 브라우저에서 게임 시작 화면까지 실행해 다음을 확인했습니다: WML 모드 로드, 좌우 패널 유지, 2열 게이지와 위치 갱신, 영업 준비 바로가기, 비활성 선택지 접기·펼치기, 전체화면 전환, 가로·데스크톱에서 추가 UI 숨김. 실제 모바일 기기와 사용자의 설치 환경에서의 최종 확인은 별도입니다.

전체화면 API가 차단된 실행 환경에서는 전체화면 전환만 사용할 수 없으며, 나머지 게임 UI는 계속 작동합니다.
