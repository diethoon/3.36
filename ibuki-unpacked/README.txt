이부키 캐릭터 애드온 — WML 수정판

대상 게임: Wayward WML 빌드 2026-10-04 이상
새 WML 모드 ID: ibuki-wml-native-fixed
필수 모드: addon-compat

중요: 이 패키지는 기존 wifeaddon_ibuki 폴더를 덮어쓰지 않습니다.
현재 설치된 기존 폴더의 메타데이터가 "게임 >=2026-09-30"이고 역할이 "아내 외형 태그"라면, 그것은 이전 버전입니다. WML은 같은 ID의 폴더가 이미 있으면 폴더를 원본으로 유지하므로, 동일 ID의 ZIP을 다시 넣어도 수정본으로 바뀌지 않습니다.

설치 절차
1. 이 ZIP을 WML 모드 관리자에 가져옵니다.
2. 목록에 새 항목 "캐릭터 애드온: 이부키 (WML 수정판)"이 생겼는지 확인합니다. ID는 ibuki-wml-native-fixed입니다.
3. 기존 항목 "캐릭터 애드온: 이부키" (wifeaddon_ibuki 폴더 등록)는 끕니다.
4. 새 항목 "캐릭터 애드온: 이부키 (WML 수정판)"은 켭니다.
5. addon-compat가 설치되어 있고 켜져 있는지 확인한 다음 새로고침합니다.

작동 방식
- 원본 아내 정의를 WML setup()에서 실행합니다.
- addon-compat의 등록 API로 게임의 아내 프리셋·이름·ID 목록에 추가합니다.
- 이미지 서버가 실제로 연결되고 ComfyUI 백엔드가 확인된 경우에만 선택 화면 초상화 생성을 요청합니다.
- 이전 preload 스크립트 주입 방식을 사용하지 않습니다.

이제 목록에 새 수정판 항목이 생기지 않는다면 ZIP을 올바른 WML 모드 관리자 창에 가져오지 못한 것입니다. 기존 폴더를 지우지 않아도 새 ID의 모드로 별도 설치됩니다.
