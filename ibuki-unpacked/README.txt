이부키 캐릭터 애드온 — WML 수정판

대상 게임: Wayward WML 빌드 2026-10-04 이상
WML 모드 ID: ibuki-wml-native-fixed
버전: 1.0.3
필요한 별도 WML 모드: 없음. 게임의 호환 브리지를 사용합니다.

설치 방법
1. 이 ZIP 파일 전체를 WML 모드 관리자에서 가져옵니다.
2. 목록에 "캐릭터 애드온: 이부키 (WML 수정판)"이 표시되고 ID가 ibuki-wml-native-fixed인지 확인합니다.
3. 이전 "wifeaddon_ibuki" 항목이 남아 있으면 WML 관리자에서 해당 항목을 삭제하거나 끕니다.
4. 새 수정판을 켜고 게임을 새로고침합니다.

중요
- 이 ZIP을 풀어 기존 wml/mods/WifeAddon_ibuki 폴더에 수동으로 덮어쓰지 마세요. 이 수정판의 WML ID가 기존 폴더 ID와 달라, ZIP을 관리자에 가져와 ID를 등록해야 합니다.
- 이 mod.js는 images-ibuki-1.js나 images/ 폴더를 직접 불러오지 않습니다. 이미지 팩 로딩 경로는 이부키 아내 등록과 별도로 확인해야 하며, 이 수정은 이미지 파일을 이동하거나 변경하지 않습니다.
- 이전 preload 스크립트 주입 방식은 사용하지 않습니다.
