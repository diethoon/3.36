Wayward MOD v4.0 검수완료판 변경점

rc10 대비
- WML 단축키·WAYWORKS 사용 중 Enter를 길게 누르면 확인 버튼이 반복 실행될 수 있던 문제 수정함.
- WML에 키 처리를 넘겨도 브라우저의 기본 반복 클릭이 확인 버튼을 누르지 않도록 보완함. 키를 놓았다가 다시 누르는 동작과 WML에서 명시적으로 켠 반복 입력 설정은 유지함.
- 게임 회귀 검사와 실제 브라우저 조합 검사를 거쳐 4.0 검수완료 기점판으로 정리함.
- 기존 게임 문구·번역·합의 표현과 MOD 기본 밸런스 44개 값은 그대로임.

rc9에서 이어지는 WML 지원
- MOD HTML에서 바로 WML 애드온을 사용할 수 있음. 별도 공식 원본 HTML 필요 없음.
- 실제 엔진과 함수 이름은 공식 2026-10-04·한패 v1.5 기반임.
- WML 단축키와 일반 밸런스 설정을 우선하도록 연결하고 중복 입력·중복 배수 적용을 방지함.
- WML 입력창에서 게임 단축키가 작동하지 않도록 보호하고, 음악 플레이어가 막는 대화창으로 오인되지 않게 조정함.
- WML 버튼 줄에 MOD 연결 상태와 설정 진입점을 추가함.

개발자 참고
- WML 0.7.0 / 공용 심볼 170개 / MOD 전용 심볼 waywardModHost.
- module-replacement 애드온이 아니라 통합 MOD HTML에 WML 브리지를 연결한 배포임.
- WML 런타임과 공용 symbols 파일은 공급본 그대로임.
- 이번 수정은 m4WmlConfirmRepeatGuard와 부팅 전 keydown capture 등록이 핵심임. repeat Enter의 기본 클릭만 방지하며 WML 핸들러 실행을 중단하지 않음.
- 구 매니저의 공식 10/4 API 49개 이름·선언 종류는 유지됨. 임의 구 애드온과 WML 애드온의 동시 사용까지 보장하지는 않음.
