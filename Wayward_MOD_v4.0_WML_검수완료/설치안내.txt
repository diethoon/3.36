Wayward MOD v4.0 — WML 검수완료 기점판

사용법
1. ZIP을 풀고 Wayward_MOD_v4.0_검수완료.html을 실행하면 됨.
2. WML을 쓰려면 HTML 옆의 wml 폴더도 함께 둬야 함. 별도의 공식 원본 HTML은 필요 없음.
3. 기존 진행은 이전 HTML에서 JSON 내보내기 후 여기서 불러오면 됨. 파일 경로가 달라지면 브라우저 자동저장이 공유되지 않을 수 있음.
4. 이미지팩·음악팩은 포함하지 않았음. 기존 파일을 그대로 연결해서 쓰면 됨.
5. 기존 WML 애드온 폴더에 합칠 때 wml/mods/mods.js의 기존 목록을 보존하고 "wayward-mod-host"를 추가하면 됨. 로더는 동봉된 WML 0.7.0 기준.

HTML 파일
Wayward_MOD_v4.0_검수완료.html은 평소 실행용, Wayward_WML_ko.html은 WML MCP가 찾는 표준 이름임. 두 파일은 같은 내용임. 하나만 골라 사용하면 됨.
별도 제공 HTML도 ZIP 안의 HTML과 바이트까지 같음. wml 폴더 없이 단독 실행하면 기존 MOD 기능만 동작함.

우선순위
WML 단축키 또는 WAYWORKS가 켜지면 기존 MOD 단축키는 양보함. 끄면 기존 MOD 키 설정이 다시 적용됨.
WML balance를 켜면 그 모드가 담당하는 일반 밸런스 항목은 WML 설정이 우선함. MOD와 배수가 이중 적용되지 않도록 연결되어 있음.
WML balance 초기값은 방문 100%·상한 8명, 기존 MOD 기본값은 125%·12명임. 기존 MOD 보관값은 삭제하지 않으며 balance를 끄면 다시 적용됨. 길드·직원 등 나머지 항목은 기존 MOD 설정을 계속 사용함.
다른 중복 기능까지 자동으로 정리하는 것은 아님. WML의 같은 역할 경고는 그대로 표시됨. 같은 애드온을 구 매니저와 WML 양쪽에 중복 설치하지 말 것.

MOD 버튼
WML 버튼 줄의 MOD는 연결 안내와 기존 설정 진입점임. 이 항목을 끈다고 HTML에 통합된 MOD 전체가 꺼지는 것은 아님.

이번 검수에서 확인한 범위를 통과한 4.0 기점판임. 외부 애드온 전체 조합의 호환 보증은 아님. 상세 범위는 QA.txt 참고.
