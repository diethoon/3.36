보존 확인
- WML 런타임과 공용 심볼 파일은 공급본과 동일. 170개 공용 심볼과 구 매니저 49개 API의 이름·선언 종류 보존.
- MOD 기본 밸런스 44개 보존. WML balance의 설정 우선순위·배수 한 번 적용·수용 상한·예약 적용·낮잠·JSON 복원을 별도 실행함.
- 이번 QA 수정에서 rc10의 한글 문자열 토큰 18,256개는 버전 표기를 제외하고 동일함. 게임 서술을 새로 번역하거나 순화하지 않음.
- 한패 v1.5 원본 5,559개 선언 중 5,403개는 원문 코드 전체가 그대로이며, rc9에서 그대로였던 원본 선언을 이번에 변경하지 않았음. 나머지는 기존 MOD·포팅 변경 범위임.
- rc9의 기존 노출 상태 표시 보완은 유지. 임의의 '(잠깐)' 상태나 별도 노출 기능을 새로 만들지 않음.

확인 한계 / 남겨 둔 사항
- 외부 애드온 76개의 소스 문법은 확인했으나, 모든 기능·모든 조합의 실행 검수는 아님.
- Windows의 구 모드 매니저 설치기, 모바일 앱, 실제 대형 이미지팩, 이미지 생성 서버는 실행하지 못함.
- 기존 침실 시간 점프 제보는 세이브 이전의 정확한 입력 순서가 없어 원래 현상을 재현하지 못함. 밤 시간 재구성·아내 제안·완료/중단 경로에서는 임의 수면을 확인하지 못했고, 명시적 수면과 시간 경과를 구분해 검사함. 이 QA로 해당 제보를 원인 확정/완치로 처리하지 않음.
- 저장 검수는 현행 저장·JSON·복원 경로 검수이며 IndexedDB 이관을 새로 구현했다는 뜻이 아님.
