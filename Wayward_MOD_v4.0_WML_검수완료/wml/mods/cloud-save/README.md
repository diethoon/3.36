# 클라우드세이브 — Google Drive 인증 버전

이 WML 모드는 Google 인증을 별도의 HTTPS 팝업 페이지에서 처리하고, 세이브 데이터는 게임 안에서 암호화한 뒤 Google Drive에 직접 전송합니다. 별도 세이브 중계 서버는 사용하지 않습니다.

## 설치 및 사용

1. `cloud-save` 폴더를 게임의 `wml/mods/`에 둡니다.
2. 기존 `wml/mods/mods.js`의 `WML.enable([...])` 목록에 `'cloud-save'`를 추가합니다. 이미 있으면 중복으로 추가하지 않습니다.
3. 게임을 기존 방식대로 실행합니다. `file://`로 HTML을 직접 열거나 HTTP(S) 웹서버를 이용할 수 있습니다.
4. 게임의 `클라우드세이브` 메뉴에서 **Google 계정으로 로그인**을 선택합니다. 별도 HTTPS 인증 창에서 계정을 선택하고 Drive 앱 전용 데이터 접근을 승인합니다.
5. 인증이 완료되면 게임 창으로 돌아와 슬롯 저장·불러오기·삭제를 이용합니다. 저장 메모는 선택 사항입니다.

## 인증 페이지 배포 필수 사항

인증 브리지는 이 저장소의 `cloud-save-auth/index.html`입니다. 이를 기존 Vercel 프로젝트 `wayward-cloud-auth`의 정적 웹 페이지로 배포해 `https://wayward-cloud-auth.vercel.app/`에서 제공해야 합니다. 프로젝트의 배포 루트가 `cloud-save-auth`를 가리키는지 확인하세요. 게임 모드는 이 HTTPS 주소를 인증 팝업으로 엽니다.

Google OAuth 웹 클라이언트의 **승인된 JavaScript 원본**에는 인증 페이지의 출처 `https://wayward-cloud-auth.vercel.app`가 등록되어 있어야 합니다. 게임을 `file://` 또는 LAN IP로 실행할 때 게임 주소 자체를 승인된 원본에 등록할 필요는 없습니다. 클라이언트 ID는 공개 식별자이며 비밀키가 아닙니다. `GOOGLE_CLIENT_SECRET`이나 다른 비밀값을 모드나 공개 저장소에 넣지 마세요.

**중요:** 코드 변경만으로 이미 배포된 Vercel 사이트가 자동 갱신되는 것은 아닙니다. 브리지 페이지를 실제 HTTPS 도메인에 배포한 뒤 테스트해야 합니다. 기존 Vercel 프로젝트의 도메인이나 배포 설정을 변경하는 작업은 이 저장소의 코드 수정과 별개입니다.

## 실행 주소 지원

- `file://`: HTML 파일 직접 실행을 유지하며 클라우드세이브 인증은 별도 HTTPS 팝업에서 처리합니다.
- `https://`: 게임 페이지에서 인증 팝업을 열어 사용할 수 있습니다.
- `http://localhost` 및 LAN HTTP: 게임 페이지에서 인증 팝업을 열어 사용할 수 있습니다. 브라우저의 팝업 정책과 연결 환경에 따라 제한될 수 있습니다.
- 인증 팝업이 차단되면 해당 게임 파일/사이트의 팝업을 허용하고 다시 시도하세요.

## 저장 및 보안

- 세이브는 게임 안에서 암호화한 뒤 Google Drive의 `appDataFolder`에 직접 전송합니다. 인증 페이지는 세이브 파일을 받거나 저장하지 않습니다.
- 액세스 토큰은 인증 팝업에서 게임 창으로 메시지 전달되며, 게임 페이지 메모리에만 보관합니다. 페이지를 다시 열면 다시 로그인해야 할 수 있습니다.
- 게임은 인증 메시지의 출처, 팝업 창 참조, 임의 상태값을 검사해 다른 창에서 온 메시지를 거부합니다.
- Drive 권한은 이 모드의 앱 전용 데이터 공간으로 제한됩니다.
- 새 세이브는 자동으로 암호화·복호화됩니다. 이전 암호화 형식의 세이브도 기존 비밀번호를 입력해 불러오고 새 형식으로 변환할 수 있습니다.
- 모드에 포함된 복호화 키는 코드를 분석하면 추출할 수 있으므로, 강한 기밀성이 필요한 자료를 보관하지 마세요.
- 슬롯 수는 별도로 제한하지 않으며, 각 슬롯에 선택 메모와 진행 정보가 표시됩니다.

## 문제 해결

- 인증 창이 열리지 않으면 브라우저의 팝업 설정을 확인하세요.
- 인증 창에서 Google 로그인이 작동하지 않으면 `https://wayward-cloud-auth.vercel.app/`에 최신 `cloud-save-auth/index.html`이 배포되었는지 확인하세요.
- Google의 `origin_mismatch` 오류가 발생하면 OAuth 클라이언트의 승인된 JavaScript 원본에 `https://wayward-cloud-auth.vercel.app`가 등록되어 있는지 확인하세요.
- 슬롯이 비어 보이면 로그인한 Google 계정이 맞는지 확인하세요. `appDataFolder`는 OAuth 앱 단위로 분리됩니다.
