Wayward Google Drive CloudSave — direct OAuth build

Install:
1. Copy the cloud-save folder into the game's wml/mods/ directory.
2. Make sure cloud-save is listed in the existing wml/mods/mods.js WML.enable([...]) list. Preserve the other entries.
3. The mod author must set GOOGLE_CLIENT_ID in mod.js to the public Google OAuth Web client ID. Never put a client secret in the mod.
4. In Google Cloud, enable Google Drive API, configure the consent screen, and register the game's HTTPS origin (or supported localhost HTTP origin) as an Authorized JavaScript origin.
5. Open the game over HTTPS or a supported localhost HTTP URL and choose 클라우드세이브 > Google 계정으로 직접 로그인.

No Vercel auth relay, GitHub Pages helper, Cloudflare save backend, user-created project, or per-user API key is required at runtime. Google Identity Services and Google Drive are the only external services used.

file:// cloud save/load is intentionally disabled; local saves and other game features remain available. Plain HTTP LAN IP addresses may not be accepted by Google OAuth; use HTTPS or localhost HTTP. Access tokens are kept in page memory only.

Never put GOOGLE_CLIENT_SECRET or other secrets in the mod ZIP or public repository.

Existing save behavior:
- New saves are encrypted/decrypted automatically by the mod.
- Older encrypted saves can be loaded with their original passphrase and converted to the current format.
- Optional slot memos and save summaries are retained.
- The key embedded in the mod is extractable by inspecting its code; do not treat it as a strong secret.
