Wayward Google Drive CloudSave — HTTPS popup auth build

Install:
1. Copy the cloud-save folder into the game's wml/mods/ directory.
2. Make sure cloud-save is listed in the existing wml/mods/mods.js WML.enable([...]) list. Preserve the other entries.
3. The existing public Google OAuth Web client ID is configured in mod.js. Never add a client secret to the mod.
4. Deploy cloud-save-auth/popup.html as a static route in the existing Vercel project at https://wayward-cloud-auth.vercel.app/popup.html.
5. In the Google OAuth Web client, keep https://wayward-cloud-auth.vercel.app as an Authorized JavaScript origin.
6. Open the game normally, including by double-clicking the HTML file (file://), or through a local/remote HTTP(S) server. Choose 클라우드세이브 > Google 계정으로 로그인. Allow the auth popup if prompted.

The game opens a separate HTTPS auth popup. Google sign-in happens there, then the access token is sent to the original game window through a state-checked postMessage. Save data is encrypted in the game and uploaded directly to Google Drive appDataFolder. The auth page is not a save relay and does not store save data.

Note: code changes do not automatically update an already-deployed Vercel project unless that deployment is configured to deploy this branch/path. Deploy the updated static auth page before testing.

Access tokens remain in game-page memory only. Popup restrictions or browser security behavior may affect file:// environments; the full flow still requires real-device testing.

Never put GOOGLE_CLIENT_SECRET or other secrets in the mod ZIP or public repository.

Existing save behavior:
- New saves are encrypted/decrypted automatically by the mod.
- Older encrypted saves can be loaded with their original passphrase and converted to the current format.
- Optional slot memos and save summaries are retained.
- The key embedded in the mod is extractable by inspecting its code; do not treat it as a strong secret.
