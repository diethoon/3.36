Wayward Google Drive CloudSave — WML v0.4.1

설치
1. cloud-save 폴더를 게임의 wml/mods/에 복사합니다.
2. wml/mods/mods.js의 WML.enable([...])에 "cloud-save"가 있는지 확인합니다. 없을 때만 기존 목록을 보존해 추가하세요.
3. 게임을 다시 열고 클라우드세이브 (Google Drive) 메뉴를 선택합니다.
4. Google 계정으로 연결을 누른 후, 열린 인증 창에서 Drive 앱 데이터 접근을 승인합니다.

인증 브리지
https://diethoon.github.io/3.36/cloud-save-auth-static/

기본 GitHub Pages 인증 브리지를 이용하므로 게임 모드 설치자마다 Vercel API, OAuth client secret 또는 redirect URI를 설정할 필요가 없습니다. Google OAuth 클라이언트의 승인된 JavaScript 원본에는 https://diethoon.github.io 가 등록되어 있어야 합니다.

file:// 실행에서는 인증 브리지의 로컬 파일 확인을 완료해야 합니다. 브라우저가 로컬 파일과 팝업 메시지를 제한하면 localhost/AWebServer/HTTPS에서 실행하세요. 공용 기기에서는 로그인 유지를 켜지 말고 사용 후 로그아웃하세요.

세이브 파일은 게임 페이지에서 AES-256-GCM으로 암호화한 뒤 Google Drive appDataFolder에 직접 업로드합니다. 모드 코드에 포함된 키는 소스 분석으로 추출할 수 있으므로 강한 비밀키가 아닙니다. 기존 Cloudflare Worker 저장 자료는 자동 이관되지 않습니다.
