Faith 이미지팩 로더 v1.0.0

기능
- WML 메뉴의 "Faith 이미지팩 로더" 버튼으로 Faith 원본의 "이미지팩 설정" 창을 엽니다.
- 기존 Faith UI의 이미지팩 등록, 등록 목록, 팩 제거 및 제작 UI를 그대로 사용합니다.
- 원본의 햄버거 메뉴와 시작 화면에 있는 "이미지팩 설정" 버튼을 숨기거나 비활성화하지 않습니다.
- 별도의 이미지팩 관리자나 등록기를 중복 구현하지 않습니다.
- 이미지 파일이나 게임 세이브를 수정하지 않습니다.

설치
1. ZIP을 풉니다.
2. 안의 faith-image-loader 폴더를 게임의 wml/mods/ 폴더에 넣습니다.
3. WML에서 "Faith 이미지팩 로더" 모드를 활성화합니다.
4. 게임을 새로고침하고 WML 메뉴의 "Faith 이미지팩 로더" 버튼을 누릅니다.

동작 방식
- 시작 화면에서 원본 "이미지팩 설정" 버튼이 보이면 그 버튼을 눌러 원본 창을 엽니다.
- 플레이 중에는 원본 햄버거 메뉴를 열고 그 안의 "이미지팩 설정" 버튼을 눌러 원본 창을 엽니다.
- 등록은 원본 wfPackScanFolder를 포함한 게임 내 기존 처리 흐름이 담당합니다.

검증 범위
- 소스 기준으로 Faith v3.0.0의 원본 설정 창은 wfPackSettingsDialog이며, 내부에서 wfPackManager를 사용하고, 폴더 등록은 wfPackFolderButton -> wfPackScanFolder를 호출합니다.
- 이 모드는 원본 HTML 내부 함수를 새로 구현하거나 원본 HTML을 수정하지 않습니다.
- 실제 기기에서 버튼 클릭 후 창이 열리는지 확인하는 런타임 검증은 별도로 필요합니다.
