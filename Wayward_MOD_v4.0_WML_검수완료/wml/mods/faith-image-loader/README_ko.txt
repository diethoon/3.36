Faith 이미지팩 로더 (실험판)

요약
- 이미지 폴더를 한 번에 하나씩 연결합니다.
- 상위 폴더 전체에 약 65,000개 파일이 있다면 그 상위 폴더를 선택하지 말고, 사용할 이미지 팩 폴더를 각각 따로 선택하세요.
- 폴더 파일은 200개 단위로 인덱싱합니다. 한 번에 20,000개가 넘으면 모바일 안전을 위해 거부하며, 실제 화면에서 매칭된 이미지에 대해서만 Blob URL을 만듭니다.
- 원본 게임 이미지 경로와 상대 경로가 일치하는 파일을 우선 사용합니다. 경로가 맞지 않으면 게임의 원래 이미지 로딩 결과를 그대로 둡니다.
- 파일은 서버로 업로드하지 않습니다.

설치
1. 이 폴더를 wml/mods/faith-image-loader/ 에 둡니다.
2. wml/mods/mods.js 목록에 "faith-image-loader"가 있는지 확인합니다.
3. 게임을 새로고침하고 WML 버튼 줄의 "Faith 이미지 로더"를 엽니다.

사용
1. "이미지 팩 폴더 선택"에서 연결할 이미지 팩 폴더 하나를 선택합니다.
2. 다른 팩도 연결하려면 새 폴더를 다시 선택합니다. 성공적으로 읽은 팩들은 누적됩니다. 같은 상대 경로가 겹치면 나중에 선택한 팩의 파일이 우선합니다.
3. "로컬 이미지 연결 사용 중" 버튼으로 이미지 덮어쓰기를 켜고 끌 수 있습니다.
4. "연결 해제"를 누르면 선택한 파일 연결을 해제하고 원래 src로 돌아갑니다.

중요
- 현재는 실험판입니다. 코드 문법 검사, WML 팩 빌드, 경로 매칭 시뮬레이션은 통과했지만 실제 Android Chrome/Samsung Browser 기기에서 이미지 출력과 UI 동작을 확인해야 합니다.
- 폴더 연결은 브라우저 메모리에 유지되므로 페이지를 새로고침하면 폴더를 다시 선택해야 합니다.
- 이미지 경로가 선택한 폴더의 상대 경로와 다르면 자동 매칭되지 않을 수 있습니다.
- 브라우저 파일 선택기에서 처리하는 파일 수 자체도 부담이 될 수 있으므로, 큰 부모 폴더 전체 대신 개별 팩 폴더를 선택하세요.
