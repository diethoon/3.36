Faith 이미지팩 로더 v1.0.0

기능
- 원래 Faith의 시작 화면과 햄버거 메뉴에 있는 "이미지팩 설정" 항목을 "Faith 이미지팩 로더"로 바꾸고, 누르면 이 모드의 이미지팩 관리 창을 엽니다.
- 좌측 하단에 별도의 WML 플로팅 버튼을 추가하지 않습니다.
- 단계별 폴더 선택 및 pack.js 탐색을 유지합니다. 이미지 파일을 한꺼번에 읽지 않고 pack.js를 찾아 원본 등록기에 전달합니다.
- 호환용 폴더 선택기와 Faith outfit ZIP 등록도 지원합니다. ZIP 내부 이미지는 실제 표시될 때 개별적으로 연결합니다.
- 이미지팩 목록을 모드 창에 표시합니다.
- 이미지 파일이나 게임 세이브를 직접 수정하지 않습니다.

설치
1. ZIP을 풉니다.
2. 안의 faith-image-loader 폴더를 게임의 wml/mods/ 폴더에 넣습니다.
3. WML에서 "Faith 이미지팩 로더" 모드를 활성화합니다.
4. 게임을 새로고침합니다.
5. 시작 화면 또는 햄버거 메뉴에서 "Faith 이미지팩 로더"를 누릅니다.

동작 방식
- 모드는 시작 화면과 햄버거 메뉴의 원본 "이미지팩 설정" 항목을 찾아 표시 이름만 교체합니다.
- 해당 항목을 누르면 모드의 이미지팩 창이 열리며, 원본 메뉴 항목의 기본 동작을 가로채 중복 UI를 띄우지 않습니다.
- 단계별 폴더 로딩은 원본 wfPackScanFolder를 사용합니다.
- ZIP 로딩은 pack.js와 이미지 경로를 확인한 뒤, ZIP 이미지 데이터는 실제 화면에 필요할 때만 압축 해제합니다.

검증 범위
- JavaScript 구문 검사 및 ZIP 패키징은 GitHub Actions에서 수행합니다.
- 실제 기기에서 메뉴가 표시되고 폴더/ZIP 이미지가 게임 내에서 출력되는지는 별도의 런타임 확인이 필요합니다.
