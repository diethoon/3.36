Faith 이미지팩 로더 (실험판 0.5.0)

이번 수정 (0.5.0)
- 이미지 폴더를 여러 개 연결해도 이전에 연결한 폴더를 유지합니다. 같은 폴더를 다시 선택하면 해당 폴더의 파일 목록을 갱신합니다.
- 메뉴에 들어갈 때마다 현재 연결된 폴더명과 각 폴더에서 찾은 이미지 수를 항상 표시합니다. 단순 총 이미지 개수만 표시하지 않습니다.
- 폴더 핸들을 하나만 저장하던 구조를 여러 폴더 목록 저장으로 변경하고, 이전 버전의 단일 저장 핸들도 읽어 이전 폴더를 이어서 복원합니다.
- 기존 <img src>뿐 아니라 인라인 CSS background-image의 url(...)도 로컬 Blob URL로 연결합니다. style 속성 변경도 감시해 다시 적용합니다.

이전 수정
- 이미지 폴더의 선택 경로에 추가 상위 폴더명이 포함되는 경우를 대비해 경로 suffix 별칭 매칭을 추가했습니다.
- 폴더 내 파일을 64개 단위로 병렬 읽어 순차 파일 접근으로 인한 대기 시간을 줄였습니다.
- 지원 브라우저에서는 선택한 폴더 핸들을 IndexedDB에 저장합니다. 새로고침 후 모드를 열면 자동 재연결을 시도하며, 권한 재승인이 필요하면 "이전 폴더 다시 연결"을 누릅니다.
- "연결 해제"는 저장된 폴더 핸들도 삭제합니다.

설치
1. 이 폴더를 wml/mods/faith-image-loader/ 에 둡니다.
2. wml/mods/mods.js 목록에 "faith-image-loader"가 있는지 확인합니다.
3. 게임을 새로고침하고 WML 버튼 줄의 "Faith 이미지 로더"를 엽니다.

사용
1. "이미지 폴더 선택 (순차 읽기)"를 누르고 이미지팩 폴더 하나를 선택합니다.
2. 다른 팩을 추가하려면 다시 선택합니다. 이미 연결한 다른 폴더는 유지되며, 같은 이름의 폴더를 다시 선택하면 해당 항목을 갱신합니다.
3. 메뉴의 상태 영역에는 연결된 폴더 이름과 폴더별 이미지 파일 수가 계속 표시됩니다. 메뉴를 닫았다가 다시 열어도 현재 상태를 확인할 수 있습니다.
4. 새로고침 후에는 저장된 폴더들을 자동 재연결하며, 권한이 필요한 경우 "저장 폴더 다시 연결"을 누릅니다.
5. "로컬 이미지 연결 사용 중" 버튼으로 연결을 켜고 끌 수 있습니다.
6. "연결 해제"를 누르면 현재 연결과 저장된 폴더 핸들을 모두 지웁니다.

중요한 제한
- 이 모드는 Faith의 네이티브 이미지팩 등록 시스템을 직접 수정하지 않습니다. DOM의 <img src>와 인라인 CSS background-image의 url(...)을 로컬 Blob URL로 바꿉니다.
- 이미지 URL과 로컬 파일 경로가 일치하는 경우에만 대체됩니다. 외부 CSS 파일의 background-image, canvas/WebGL 또는 다른 내부 렌더링 경로는 적용되지 않을 수 있습니다.
- 폴더 핸들 저장/복원은 브라우저의 File System Access API, IndexedDB 및 권한 정책에 따라 달라집니다. 폴더 파일 자체를 복사하거나 서버로 업로드하지 않습니다.
- 이 버전은 폴더 누적 연결과 폴더별 상태 표시를 보완한 실험판입니다. JavaScript 구문 검사와 정적 로직 검토 후에도 Android 실기기에서 폴더 선택 시간, 새로고침 후 복원, 실제 Elena 이미지 출력은 별도 검증이 필요합니다. 이 버전을 완성 검증판으로 간주하지 마세요.
