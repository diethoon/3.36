Faith 이미지팩 로더 (실험판 0.1.2)

요약
- 원본 게임의 이미지 URL을 유지하면서, 선택한 로컬 이미지 파일이 경로와 일치할 때 해당 이미지에만 Blob URL을 연결합니다. 게임의 이미지팩 등록 시스템 자체를 교체하지는 않습니다.
- 지원 브라우저에서는 먼저 "폴더 선택 (단계 처리)"를 사용합니다. File System Access API로 폴더를 순회하며 200개 단위로 처리해, 대형 폴더의 FileList를 한 번에 만드는 부담을 줄입니다.
- 단계 처리 폴더 선택을 지원하지 않는 브라우저에서는 기존 "이미지 팩 폴더 선택"을 사용합니다.
- 한 폴더에서 20,000개가 넘는 이미지 파일은 거부합니다. 가능한 한 이미지 팩 하위 폴더를 선택하세요.
- 실제 화면에서 매칭된 이미지에 대해서만 Blob URL을 만듭니다. 파일을 서버로 업로드하지 않습니다.

설치
1. 이 폴더를 wml/mods/faith-image-loader/ 에 둡니다.
2. wml/mods/mods.js 목록에 "faith-image-loader"가 있는지 확인합니다.
3. 게임을 새로고침하고 WML 버튼 줄의 "Faith 이미지 로더"를 엽니다.

사용
1. 가능하면 "폴더 선택 (단계 처리)"를 눌러 이미지 팩 폴더 하나를 선택합니다.
2. 해당 버튼이 브라우저에서 지원되지 않으면 "이미지 팩 폴더 선택"을 사용합니다.
3. 다른 팩도 연결하려면 폴더를 다시 선택합니다. 성공적으로 읽은 팩들은 누적됩니다. 동일한 상대 경로가 겹치면 나중에 선택한 팩의 파일이 우선합니다.
4. "로컬 이미지 연결 사용 중" 버튼으로 로컬 이미지 연결을 켜고 끕니다.
5. "연결 해제"를 누르면 연결한 파일을 비우고 원래 이미지 src로 복원합니다.

제한 및 검증 상태
- 모드는 현재 DOM의 <img src>를 대상으로 합니다. CSS 배경 이미지, canvas/WebGL 렌더링, 또는 다른 경로를 사용하는 이미지에는 적용되지 않을 수 있습니다.
- 폴더 핸들이나 인덱스는 페이지 새로고침 후 보존되지 않으므로 다시 선택해야 합니다.
- 경로가 선택한 폴더의 상대 경로와 다르면 자동 매칭되지 않을 수 있습니다.
- JS 파싱 검사와 WML 팩 패키징은 통과했습니다. 실제 Android Chrome/Samsung Internet 및 게임 내부 캐릭터별 이미지 출력은 아직 기기에서 확인해야 합니다. 따라서 이 버전을 완성 검증판이 아닌 실험판으로 취급하세요.
