Faith 이미지팩 로더 (실험판 0.3.0)

이번 수정
- 이미지 폴더의 선택 경로에 추가 상위 폴더명이 포함되는 경우를 대비해 경로 suffix 별칭 매칭을 추가했습니다.
- 폴더 내 파일을 64개 단위로 병렬 읽어 순차 파일 접근으로 인한 대기 시간을 줄였습니다.
- 지원 브라우저에서는 선택한 폴더 핸들을 IndexedDB에 저장합니다. 새로고침 후 모드를 열면 자동 재연결을 시도하며, 권한 재승인이 필요하면 "이전 폴더 다시 연결"을 누릅니다.
- "연결 해제"는 저장된 폴더 핸들도 삭제합니다.

설치
1. 이 폴더를 wml/mods/faith-image-loader/ 에 둡니다.
2. wml/mods/mods.js 목록에 "faith-image-loader"가 있는지 확인합니다.
3. 게임을 새로고침하고 WML 버튼 줄의 "Faith 이미지 로더"를 엽니다.

사용
1. "이미지 폴더 선택 (순차 읽기)"를 누르고 이미지팩 폴더 하나를 선택합니다.
2. 다른 팩을 추가하려면 다시 선택합니다.
3. 새로고침 후에는 저장된 폴더를 자동 재연결하며, 권한이 필요한 경우 "이전 폴더 다시 연결"을 누릅니다.
4. "로컬 이미지 연결 사용 중" 버튼으로 연결을 켜고 끌 수 있습니다.
5. "연결 해제"를 누르면 현재 연결과 저장된 폴더 핸들을 지웁니다.

중요한 제한
- 이 모드는 Faith의 네이티브 이미지팩 등록 시스템을 직접 수정하지 않습니다. 현재 DOM의 <img src>를 로컬 Blob URL로 바꾸는 방식입니다.
- 따라서 이미지 URL과 로컬 파일 경로가 일치하는 경우에만 대체됩니다. CSS 배경 이미지, canvas/WebGL 또는 다른 내부 렌더링 경로는 적용되지 않을 수 있습니다.
- 폴더 핸들 저장/복원은 브라우저의 File System Access API, IndexedDB 및 권한 정책에 따라 달라집니다. 폴더 파일 자체를 복사하거나 서버로 업로드하지 않습니다.
- JavaScript 구문은 별도로 검사했습니다. Android Firefox/Chrome에서 폴더 선택 시간, 새로고침 후 복원, Elena 이미지 출력은 아직 실제 기기에서 재검증하지 않았습니다. 이 버전을 완성 검증판으로 간주하지 마세요.
