## 설치

1. 게임을 HTTPS 또는 로컬 웹서버에서 엽니다.
2. 게임 안에서 WML 모드 관리자를 엽니다.
3. `mobile-portrait-layout.zip`을 모드 관리자 창으로 끌어 놓거나 파일 선택 기능으로 가져옵니다.
4. 설치 확인 후 게임을 새로고침합니다.

WML 폴더에 직접 설치하는 경우에는 `wml/mods/mobile-portrait-layout/mod.js`에 놓고 `wml/mods/mods.js`의 ID 목록에 `mobile-portrait-layout`을 추가해야 합니다.

- 기존 좌우 패널 전환 버튼을 그대로 사용합니다.
