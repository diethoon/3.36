# 모바일 세로 60:40 레이아웃 (WML)

- 모드 ID: `mobile-portrait-layout`
- 버전: `1.1.0`
- 대상: WML `2026-10-04` 빌드 및 `2026-10-24-pre7` 호환 심볼 빌드

## 기존 v1.0.0에서 업데이트

이전 ZIP은 `2026-10-24-pre7`의 원시 심볼 이름만 가정했습니다. `2026-10-04` 빌드에서는 게임 상태 선택기 이름이 달라 모드 초기화가 중단될 수 있었고, 그 경우 CSS도 삽입되지 않아 화면이 그대로였습니다. v1.1.0은 레이아웃 CSS를 먼저 적용하고, 상태 위젯의 심볼을 현재 빌드의 의미 이름과 이전 이름 양쪽에서 찾도록 바꿨습니다.

## 설치 / 업데이트

1. 게임을 HTTPS 또는 로컬 웹서버에서 엽니다.
2. WML 모드 관리자에서 기존 `mobile-portrait-layout` v1.0.0을 제거합니다.
3. 이 ZIP을 다시 설치하고 설치 목록에 ID `mobile-portrait-layout`, 버전 `1.1.0`이 표시되는지 확인합니다.
4. 게임을 새로고침한 후 새 게임 또는 진행 중인 게임 화면에서 확인합니다.

직접 설치한다면 파일을 `wml/mods/mobile-portrait-layout/mod.js`에 두고 `wml/mods/mods.js` 활성 ID 목록에도 `mobile-portrait-layout`을 추가해야 합니다.

## 변경 내용

- 세로 모바일에서 기존 메인 패널은 남은 폭(약 60%), 상태·행동 패널은 40%를 차지합니다.
- 기존 좌우 패널 전환 버튼과 선택지 이벤트를 그대로 사용합니다.
- 상태 위젯의 심볼을 해당 게임 빌드에서 찾을 수 있을 때만 기존 상태 컴포넌트를 선택지 위에 고정 표시합니다.
- 상태 위젯 바인딩을 찾지 못하더라도 레이아웃 CSS는 적용되며, 모드 초기화를 실패 처리하지 않습니다.
- 가로 화면과 데스크톱에서는 CSS 변경을 적용하지 않습니다.

게임 HTML, 세이브·로드, RNG, Undo, ID, 경제, 공급 및 캐릭터 행동 로직은 수정하지 않습니다.
