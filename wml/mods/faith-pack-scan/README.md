# Faith 이미지팩 등록 개선 모드

## 목적
대량의 이미지 파일이 포함된 image-packs 폴더를 선택한 뒤 등록 UI가 멈추는 문제를 줄이기 위한 WML 모드입니다.

## 동작
- 기존 Faith HTML 파일은 수정하지 않습니다.
- 폴더 선택 결과를 384개 파일씩 나눠 확인하고 브라우저에 실행 시간을 양보합니다.
- 기존 Faith 등록 함수에는 image-packs/*/pack.js 파일만 전달합니다. 이미지 파일은 읽거나 HTML에 삽입하지 않습니다.
- 등록 중/완료/실패 상태를 화면에 표시합니다.
- 등록기 함수를 현재 WML 런타임에서 찾을 수 없으면 원래 폴더 선택 동작을 가로채지 않습니다.

## 설치
1. Faith 게임 폴더의 wml/mods/ 아래에 faith-pack-scan/ 폴더를 만듭니다.
2. 그 안에 mod.js를 넣습니다.
3. 게임을 새로 열고 WML 모드 목록에서 Faith 이미지팩 등록 개선을 활성화합니다.
4. 이미지팩 관리 화면에서 기존처럼 image-packs 폴더를 선택합니다.

## 주의
이 모드는 폴더 선택 후 JavaScript 측의 불필요한 파일 처리량을 줄이는 우회책입니다. Android 파일 선택기 자체가 대규모 폴더를 반환하는 데 걸리는 시간까지 없애지는 못합니다. 실제 Android 기기에서 등록 성공 여부를 확인해야 합니다.
