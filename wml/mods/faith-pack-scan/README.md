# Faith 이미지팩 등록 개선 모드

## v0.2.0 변경점
v0.1.0은 게임 내부 등록 함수를 WML API에서 찾지 못하면 원래 처리에 맡기는 구조여서, 대량 폴더에서 동일한 멈춤이 반복될 수 있었습니다.

v0.2.0은 등록 함수에 직접 접근하지 않습니다. 폴더 선택 이벤트를 먼저 가로채고, 파일 목록을 256개씩 나눠 확인한 뒤 `image-packs/*/pack.js`만 남긴 `FileList`를 만들어 게임의 원래 이벤트를 다시 실행합니다. 이미지 파일 6만여 개는 원래 등록기에 전달하지 않습니다.

화면에 모드 활성화 및 처리 상태를 표시합니다. 브라우저가 `DataTransfer`를 지원하지 않으면 대량의 원래 처리를 실행하지 않고 오류를 표시합니다.

## 설치
1. Faith 게임 폴더의 `wml/mods/faith-pack-scan/`에 이 폴더의 `mod.js`를 넣습니다.
2. 게임을 완전히 종료했다가 다시 열고 WML에서 **Faith 이미지팩 등록 개선** 모드를 활성화합니다.
3. 이미지팩 관리 화면에서 `image-packs` 폴더 자체를 선택합니다.
4. 선택 버튼 아래에 **“이미지팩 등록 개선 모드 활성화됨”**이 보이는지 확인합니다.
5. 선택 후 상태 문구가 바뀌는지, 게임의 이미지팩 등록 결과가 표시되는지 확인합니다.

## 해석
- 활성화 문구 자체가 안 보임: 모드가 로드되지 않았거나 선택기 입력 요소를 찾지 못한 것입니다.
- “파일 목록 정리 중…”에서 멈춤: 폴더 선택 결과 처리 단계가 문제일 수 있습니다.
- “pack.js …개를 게임 등록기에 전달했습니다”가 나오지만 등록이 안 됨: 이벤트 재실행/게임 등록 단계에서 추가 조사가 필요합니다.
- 검은 화면이 계속되지만 상태 문구가 전혀 바뀌지 않음: 브라우저/파일 선택기에서 change 이벤트가 전달되기 전 단계에서 멈췄을 가능성이 있습니다.

실제 Android 기기에서 성공 여부를 검증한 상태는 아닙니다. 원본 게임 HTML과 main 브랜치는 수정하지 않습니다.
